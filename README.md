# HY CARE GUIDE (한양 케어가이드)

> 🔗 배포 주소: [https://hello-page-wine.vercel.app](https://hello-page-wine.vercel.app)
> 📦 저장소: [https://github.com/freebabi/hy-care-guide](https://github.com/freebabi/hy-care-guide)

환자정보시스템이 아니라 **"환자 안내 콘텐츠 + 전달 지원 시스템"**으로 동작하는
프로토타입입니다. EMR/EHR과 연동해 환자 개인정보를 직접 보유하지 않고, 직원이
콘텐츠를 검색·미리보기한 뒤 SMS/QR/카카오 알림톡으로 "전달에 필요한 문구와
링크"만 준비합니다. 실제 발송은 병원 기존 EHR(SMS)·향후 승인될 카카오
비즈메시지 API가 수행합니다.

> 서비스 철학: "필요한 순간, 필요한 안내를."

## 구성

- **직원용 웹** (`/`, `/cms`, `/history`, `/dashboard`) — 콘텐츠 검색/필터 → 미리보기 → 전달 방법(SMS/QR/카카오) 선택 → 문구·링크 복사까지의 업무 흐름
- **환자용 모바일 웹** (`/c/[slug]`) — 콘텐츠별 고정 URL로 진입하는 안내 상세 화면(개인정보 없음, "OOO님" 표시 없음)

## 실행

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 접속 시 직원용 홈("환자 안내 콘텐츠")으로 진입합니다.

## 기술 스택

- Next.js(App Router) + TypeScript + Tailwind CSS
- 발송 지원(Mock): `src/lib/care-guide/notification-service.ts` — SMS/카카오 문구 생성과 실제 발송 실행을 분리해, Phase 2에서 실제 API를 붙일 때 이 파일만 확장하면 되도록 설계
- 데이터: `src/lib/care-guide/guides-data.ts` (정적 시드, 50개) + `localStorage`(CMS 편집분/발송 이력 — 프로토타입용 "로컬 DB" 역할)

## 프로토타입 범위와 한계

- 환자 개인정보(이름·등록번호·전화번호)는 이 서비스 어디에도 저장·조회하지 않습니다. 환자 선택과 실제 발송은 병원 기존 EHR에서 이루어집니다.
- 카카오 알림톡/SMS는 실제 API를 연동하지 않은 Mock이며, "문구/링크 복사"·"QR 생성"까지만 지원합니다.
- 콘텐츠 URL(`/c/[slug]`)은 만료 없는 고정 링크이며 개인 식별값을 포함하지 않습니다.
- 안내 콘텐츠 중 구체적인 수치(금식 시간, 복용법 등)는 프로토타입 예시이며, **병원 공식 검토 없이 실제 환자 안내에 사용해서는 안 됩니다.** (`needsClinicalReview: true`로 표시된 항목)

## 실제 서비스 전환 시 반드시 검토해야 할 항목

- **콘텐츠 서버 DB 이관**: 현재 CMS 편집 내용은 브라우저 localStorage에만 저장됩니다. 서버 DB로 옮기지 않으면 OG 메타태그(카톡/문자 링크 미리보기)처럼 서버에서 실행되는 부분이 CMS 최신 상태를 반영하지 못합니다.
- **접근 권한/사용자 인증**: 현재 콘텐츠 등록·수정·게시 버튼이 로그인 없이 누구에게나 노출됩니다. 인증 도입 후 관리자 역할로 제한 필요
- **접속 로그/감사 추적**: 발송 이력은 PII 제로 원칙에 따라 담당 직원 정보를 남기지 않습니다. 인증이 붙으면 직원 계정 ID(이름 아님) 정도의 감사 추적을 다시 고려
- **버전 이력 관리**: 현재 콘텐츠 저장 시 버전 번호만 증가하며, 과거 버전 조회·롤백은 지원하지 않습니다
- **성능(느린 네트워크)**: Slow 3G(400kbps, 지연 400ms) 시뮬레이션 기준 프로덕션 빌드에서도 첫 화면 표시까지 약 6.5~7초가 걸립니다(dev 서버는 약 13초). 정적 생성(SSG) 전환, 클라이언트 번들 축소 등 원인 분석과 최적화가 필요합니다
- **EMR 연계 보안**: 향후 환자 데이터 조회가 필요해지면, 프론트엔드가 EMR에 직접 접근하지 않고 인증된 백엔드 API 레이어를 경유하도록 구성
- **외부 메시징 연계**: 카카오 알림톡/SMS 발송사와의 실제 계약, 발신 프로필/템플릿 사전 심사 및 등록
- **콘텐츠 임상 검토**: 모든 환자 안내 콘텐츠는 게시 전 관련 진료과·간호부·약제부 등의 공식 검토를 거쳐야 합니다
